# A* 3D Pathfinding Demo

使用 C++ 实现的三维路径搜索算法，支持动态可视化展示。

## 项目结构

```
Astar/
├── .gitignore        # Git 忽略规则
├── Makefile          # 构建系统
├── README.md         # 项目文档
├── types.h           # 公共类型定义 (Pos3D, CellType, SearchResult, ...)
├── map3d.h           # 3D 地图模块接口
├── map3d.cpp         # 3D 地图生成实现 (障碍物、危险区、起点/终点)
├── astar.h           # A* 搜索算法接口
├── astar.cpp         # 加权 A* 算法实现 (Weighted A*)
├── visualizer.h      # 终端可视化接口
├── visualizer.cpp    # 终端可视化实现 (ANSI 色彩、动画、交互探索)
├── main.cpp          # 程序入口 (命令行参数解析)
└── build/            # 编译中间产物 (自动生成，不纳入版本控制)
```

## 需求覆盖

| # | 需求 | 实现方式 |
|---|------|----------|
| 1 | 在 1000×1000×10 三维地图中搜索最短路径 | 支持任意维度地图，命令行 `-w 1000 -h 1000 -d 10` 配置，10M 网格单元实测通过 |
| 2 | 终点有 2+ 个，随机分布在不同层 | 贪婪最近邻策略：从起点出发，依次访问最近未访问终点，支持 2~N 个终点 |
| 3 | 换层代价 > 平面代价，总代价尽可能小 | 默认换层代价 5×（可配 `-L`），平面移动 1×，A* 自动权衡换层 vs 绕行 |
| 4 | 不要求最优，综合考虑运行时间 | 采用 **加权 A\*** (Weighted A\*)，权重默认 2.0（可配 `-W`），牺牲少量最优性换取极大速度提升 |
| 5 | 每个位置可向东南西北 + 上下 6 方向搜索 | 严格 6 邻域移动模型：East, West, South, North, Up, Down |
| 6 | 随机障碍物：不可触碰（保持距离）+ 可触碰但高代价 | **阻挡障碍**: 完全不可通行，周围自动生成 Danger Zone 缓冲区<br>**高代价障碍**: 可通行但代价 10×（可配 `-C`）<br>**Danger Zone**: 紧邻阻挡障碍，代价 100×（可配 `-D`），强力阻止穿越 |

### 核心算法

- **加权 A\* (Weighted A\*)**: `f(n) = g(n) + w × h(n)`，其中 `w ≥ 1.0`
  - `w = 1.0` 为标准 A\*，保证最优但较慢
  - `w = 2.0` 默认值，在速度与质量间取得平衡
  - 启发函数 `h(n)` 为三维曼哈顿距离：`|Δx| + |Δy| + layer_penalty × |Δz|`
- **多终点处理**: 贪心最近邻，每个 segment 独立执行 A\*
- **地图规模**: 支持最高 1000×1000×10（1 千万节点），稀疏状态存储，内存 ~90MB

### 地图生成

1. **阻挡障碍**: 随机游走生成障碍簇，覆盖率默认 6~8%
2. **Danger Zone**: 每个阻挡障碍的 6 邻域方向标记为危险区（保持距离）
3. **高代价障碍**: 在自由区域随机放置，覆盖率默认 4~5%
4. **起点 & 终点**: 在自由区域随机放置，终点分布在不同层，彼此保持间距

## 快速开始

### 构建

```bash
cd Astar
make          # 编译项目 (中间文件在 build/ 目录)
```

### 运行

```bash
# 交互式演示模式 (小地图 + 终端动画 + 路径探索)
make demo
# 或
./astar_demo --demo

# 全尺寸 1000×1000×10 (文本模式，仅输出统计)
make full

# 快速冒烟测试
make test

# 自定义所有参数
./astar_demo --text -w 500 -h 500 -d 8 -g 4 -b 0.07 -c 0.04 -W 1.5 -L 6.0 -D 80.0 -s 123

# 只去最近的一个终点
./astar_demo --text --visit-one -w 1000 -h 1000 -d 10
```

### 命令行参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `-w <int>` | 地图宽度 | 1000 |
| `-h <int>` | 地图高度 | 1000 |
| `-d <int>` | 地图层数 | 10 |
| `-g <int>` | 终点数量 | 3 |
| `-b <float>` | 阻挡障碍密度 | 0.08 |
| `-c <float>` | 高代价障碍密度 | 0.05 |
| `-s <int>` | 随机种子 | 42 |
| `-W <float>` | A* 权重 (≥1.0) | 2.0 |
| `-L <float>` | 换层代价倍数 | 5.0 |
| `-C <float>` | 高代价障碍倍数 | 10.0 |
| `-D <float>` | Danger Zone 代价倍数 | 100.0 |
| `--demo` | 演示模式 (小地图 + 可视化) | — |
| `--text` | 纯文本模式 (无终端绘图) | — |
| `--visit-one` | 只去最近终点 (不全部访问) | — |
| `--help` | 显示帮助信息 | — |

## 可视化操作

`--demo` 模式下提供两阶段可视化：

### 阶段一：路径动画

- 搜索完成后逐帧绘制完整路径
- 显示路径在各层的走线情况
- **Space** — 跳过动画直接显示最终路径
- **q** — 退出

### 阶段二：交互探索

- 使用彩色符号展示地图
- 可在不同层之间切换查看路径
- **1-9** — 切换到对应层
- **方向键 / WASD / HJKL** — 平移视口
- **Home** — 跳转到起点位置
- **0** — 循环切换图层
- **q** — 退出

### 颜色图例

| 颜色 | 含义 |
|------|------|
| ⬜ 灰色 `·` | 自由空间 |
| 🟥 红色 `█` | 阻挡障碍 (不可通行) |
| 🟨 金色 `▓` | 高代价障碍 (10× 代价) |
| 🟪 洋红 `▒` | Danger Zone (100× 代价，应避开) |
| 🟩 绿色 `S` | 起点 |
| 🟦 蓝色 `G` | 终点 |
| 🟡 亮黄 `*` | 搜索到的路径 |
